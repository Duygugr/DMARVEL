# 🕷️ DMarvel

DMarvel, **HTML, CSS ve JavaScript** kullanılarak geliştirilmiş, modern ve responsive tasarıma sahip Marvel temalı bir web projesidir. Projede Marvel filmleri hakkında bilgiler dinamik olarak görüntülenmektedir.

## 🚀 Özellikler

* 🎬 Marvel film kartları
* ⭐ API üzerinden IMDb puanlarını görüntüleme
* 📝 Film açıklamaları
* 🎨 Modern ve responsive kullanıcı arayüzü
* 📱 Mobil uyumlu tasarım

## 🛠️ Kullanılan Teknolojiler

* HTML5
* CSS3
* JavaScript
* API
